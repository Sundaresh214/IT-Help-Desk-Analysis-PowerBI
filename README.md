# IT Help Desk Analysis Dashboard

An interactive Power BI dashboard for analyzing IT help desk tickets and identifying trends in ticket volume, priority, severity, departments, resolution time, and customer satisfaction.

## 📌 Project Overview

IT support teams handle a large number of service requests and incident tickets. This project uses Power BI to transform IT ticket data into an interactive dashboard that helps users understand support demand and monitor important operational metrics.

The dashboard is designed to support data-driven decision-making by presenting ticket information in a clear and interactive format.

## 🎯 Project Objectives

- Analyze the overall volume of IT support tickets.
- Understand ticket distribution across departments and business units.
- Identify high-priority and high-severity support issues.
- Analyze different types of IT tickets.
- Monitor ticket resolution duration using Days Open.
- Evaluate user satisfaction.
- Support better workload analysis and IT service decision-making.

## 📊 Key Analysis Areas

- Total IT Tickets
- Department-wise Analysis
- Business Unit Analysis
- Ticket Type Distribution
- Priority Analysis
- Severity Analysis
- Days Open / Resolution Time Analysis
- Employee and User Analysis
- Gender and Job Classification Analysis
- Customer Satisfaction Analysis
- IT Owner Analysis

## 🛠️ Tools and Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data transformation and cleaning
- **DAX** – Calculated measures and analytical calculations
- **Data Analysis** – Identifying patterns and trends

## 🚀 How to Use This Project

1. Clone or download this repository.
2. Install Power BI Desktop.
3. Open `IT Analysis.pbit`.
4. If prompted, provide the required data source information.
5. Refresh the data.
6. Explore the interactive dashboard using filters and visualizations.

## 📈 Business Value

This dashboard helps organizations better understand IT support operations. By identifying frequently occurring ticket categories, high-priority issues, and trends in resolution time, IT teams can improve resource allocation and service quality.
